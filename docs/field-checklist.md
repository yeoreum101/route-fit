# 현장조사 채점 체크리스트

장소의 3속성(광주다움 · 상권 연계성 · 체류 유도성)은 **예/아니오 체크리스트**로 매긴다.
"몇 점 줄까?"라는 판단을 "맞나, 아니나?"라는 사실 확인으로 바꿔, 채점하는 사람에 따라 점수가 달라지지 않게 하기 위해서다.

- 항목 정의 원본: [`data/checklist.json`](../data/checklist.json) (이 문서와 다르면 JSON이 맞다)
- 입력: 장소 관리 화면(`/admin.html`) → 장소 선택 → 맨 아래 **현장조사 체크리스트**

## 점수 계산

```
속성 점수 = 1 + (그 속성 항목 4개의 값 합계)        → 1 ~ 5점
항목 값   = 자동 항목: 0 또는 1
            수동 항목: 체크한 팀원 비율 (2명 중 1명이면 0.5)
```

- 체크리스트를 **한 명이라도 내면** 그 장소의 점수와 '지역상권 장소' 여부는 체크리스트로 계산된다(직접 입력 칸은 잠긴다).
- 아무도 내지 않은 장소는 직접 입력한 점수를 그대로 쓴다.
- 장소 정보(체류시간·지출·태그·영업시간)를 고치면 자동 항목도 즉시 다시 계산된다.

## 항목

**자동** = 장소 정보로 시스템이 계산 · **수동** = 팀원이 체크하고 근거를 남김

### 광주다움 — 광주에서만 할 수 있는 경험인가

| 항목 | 구분 | 확인 방법 |
|---|---|---|
| 5·18 등 광주 근현대사 사건의 현장이다 | 수동 | 5·18 사적지 목록 등 공식 지정 여부 |
| 지정·등록 문화유산이거나 근대건축물이다 | 수동 | 국가유산청 문화유산 검색 |
| 광주 고유의 음식·예술·인물과 직접 관련된다 | 수동 | 광주시 대표 음식·음식 거리 지정, 공식 소개 자료 |
| 같은 자리에서 30년 이상 운영했다 | 수동 | 개관·개업 연도 (공식 소개, 인허가 자료) |

### 상권 연계성 — 방문이 주변 소상공인 매출로 이어지는가

| 항목 | 구분 | 확인 방법 |
|---|---|---|
| 프랜차이즈나 대기업 직영이 아니다 (공공시설은 체크) | 수동 | 가맹사업 정보공개서 조회, 상호 검색 |
| 전통시장·상점가·골목상권 구역 안에 있다 | 수동 | 소상공인시장진흥공단 전통시장·상점가 자료 |
| 반경 300m 안에 소상공인 점포가 많다 | 수동 | 소상공인 상가(상권)정보 공공데이터 |
| 1인 예상 지출이 0원보다 크다 (그 자리에서 매출이 생긴다) | 자동 | 예상 지출 |

### 체류 유도성 — 오래 머물고 이어서 다른 곳에 가게 하는가

| 항목 | 구분 | 확인 방법 |
|---|---|---|
| 머무는 시간이 60분 이상이다 | 자동 | 머무는 시간 |
| 앉아서 쉴 수 있는 자리(좌석·벤치)가 있다 | 수동 | 현장 확인 (사진) |
| 할 거리 태그가 2개 이상이다 | 자동 | 취향 태그 |
| 19시 이후까지 운영한다 (경기·공연 전후로 이어 가기 좋음) | 자동 | 영업시간 |

12개 중 자동 4개, 수동 8개. 수동 중 '반경 300m 점포 수'는 공공데이터로 자동화할 수 있다.

### 지역상권 장소

체크리스트가 있으면 **'프랜차이즈 아님'과 '시장·상점가 구역' 두 항목이 모두 0.5 이상**인 장소를 지역상권 장소로 본다.
실증 통계의 '지역상권 비율'이 이 값으로 계산된다.

## 조사 방법

1. **두 명 이상이 서로 보지 않고** 각자 체크한다. 화면에서 채점자를 고르거나 '+ 새 채점자'로 이름을 넣는다.
2. 수동 항목을 체크할 때 **근거**(링크, 사진 파일명, 메모)를 남긴다. 체크하지 않은 항목도 확인한 근거가 있으면 남긴다.
3. 의견이 갈린 항목은 노란색 **불일치**로 표시된다. 근거를 같이 보고 맞춘 뒤, 각자 자기 체크리스트를 고쳐 저장한다.
4. 다 맞췄으면 **현장 검증 완료**를 체크한다.
5. 장소 관리 화면의 **JSON 내보내기**로 받은 `places.json` · `checklists.json` 등을 `data/`에 커밋한다. 다른 팀원 환경도 같은 데이터로 시작한다.

## 아직 정할 것

| 항목 | 현재 | 정할 것 |
|---|---|---|
| 반경 300m 점포 수 기준 | "많다"(판단) | 후보 장소의 점포 수를 모은 뒤 **중간값**을 기준으로 정하고 자동화 |
| 30년 · 60분 · 19시 기준 | 출발점 | 실제 장소에 적용해 보고 점수가 한쪽으로 몰리면 조정 |
| 항목 무게 | 모두 1점 | 특정 항목을 2점으로 둘지 (처음에는 같게 가는 것을 권함) |

## 바꾸는 방법

- 문구(`label`)·확인 방법(`how`)은 `data/checklist.json`에서 고치고 서버를 재시작한다.
- 항목 `key`는 바꾸지 않는다. 이미 저장한 체크가 사라진다.
- 자동 항목의 기준(60분, 19시 등)은 `routefit/checklist.py`의 `AUTO_RULES`에 있다.
